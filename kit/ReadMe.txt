THE cmd FILES IN THIS KIT ARE SETUP FOR THE COMMUNITY EDITION. You must manually edit them for other editions.
Run WLProjectWizardInstaller.cmd to install the Project wizard (which adds and entry to VS's File/New-Project)
And WLModulewizardVSinstaller to install the "Item" wizard, which adds an entry to VS's right mouse "Add Item..." menu.
These files are customized (slightly) for each version of Visual Studio

Once the two cmd files have been run successfully, the downloaded zip file and these files
unzipped from it are no longer needed.
